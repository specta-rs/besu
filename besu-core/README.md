# besu-core

The traits and SQL primitives that Besu is built on: `Dialect`, `Driver`, `Sql`, `Value` and row decoding. It has no query API and no database, so SQL can be built with nothing attached.

Part of [Besu](https://github.com/specta-rs/besu), a typesafe, async, database-agnostic SQL
query builder for Rust. The query you write is the SQL that runs.
