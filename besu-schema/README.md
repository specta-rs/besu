# besu-schema

The schema intermediate representation, the differ, DDL generation and the migration runner. One serialisable schema type is shared by the derive macro, introspection and snapshots.

Part of [Besu](https://github.com/specta-rs/besu), a typesafe, async, database-agnostic SQL
query builder for Rust. The query you write is the SQL that runs.
