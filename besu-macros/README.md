# besu-macros

The `#[derive(Table)]` macro for Besu. Enable the `derive` feature on `besu` instead of depending on this crate directly, unless you want a faster compile.

Part of [Besu](https://github.com/specta-rs/besu), a typesafe, async, database-agnostic SQL
query builder for Rust. The query you write is the SQL that runs.
